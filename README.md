# Lucky Cat Mahjong

The website of [Lucky Cat Mahjong](https://luckycatmahjong.com), a mahjong community founded in New York City. We teach and play Hong Kong mahjong.

## On the site

- **[Play Mahjong](https://luckycatmahjong.com/play-mahjong/):** a free Hong Kong mahjong game against three computer players, with a coach that explains its advice. It plays in English or Simplified Chinese, and works offline after one visit.
- **[Mahjong Rules](https://luckycatmahjong.com/hong-kong-mahjong-rules/):** how to play Hong Kong mahjong, from the tiles to scoring.
- **[Points Guide](https://luckycatmahjong.com/hong-kong-mahjong-scoring/):** every scoring pattern, and a calculator for a hand's faan and points.
- **[Personality Quiz](https://luckycatmahjong.com/which-mahjong-tiles-are-you/):** which mahjong tile are you?
- **[Events](https://luckycatmahjong.com/events/)** and **[Community](https://luckycatmahjong.com/community/):** mahjong nights, tournaments and workshops in New York City.

## About this repository

This repository holds the published build of the site, in `public/`. GitHub Pages serves it at [luckycatmahjong.com](https://luckycatmahjong.com) (`.github/workflows/pages.yml` deploys it on every change).

The build is made from a private source repository on each release. Every file in `public/` is replaced on the next release, so changes made here are not kept. The scripts are bundled and obfuscated, and each page sets a Content-Security-Policy.

## Privacy

The site uses Google Analytics, with a cookie choice on every page. The [Privacy Policy](https://luckycatmahjong.com/privacy-policy/) says what is collected and why. The [Terms and Conditions](https://luckycatmahjong.com/terms-and-conditions/) and [Refund Policy](https://luckycatmahjong.com/refund-policy/) cover events and tickets.
